STEP 4: FAILURE DIAGNOSIS ✓
================================================================================

File: tests/evaluation/phase4_benchmark.py (analyze_missed_queries method)

Failure Mode Classification:

1. Embedding/Semantic Mismatch
   - Root cause: Query embedding far from rule embeddings
   - Detection: Vector channel retrieves nothing

2. Lexical Mismatch
   - Root cause: Query has no keyword overlap with rules
   - Detection: BM25 + FTS retrieve nothing

3. Missing or Stale Embedding
   - Root cause: Rule lacks embedding (not backfilled)
   - Detection: Query succeeds, but rule missing

4. Workspace Filter Issue
   - Root cause: Relevant rule in different workspace
   - Detection: Rule exists but filtered out

5. RRF Ranking Issue
   - Root cause: Relevant rule retrieved but ranked low
   - Detection: Rule in vector/BM25 but not top-K

6. Insufficient Top-K
   - Root cause: Relevant rule beyond top-10
   - Detection: Increase top-K to retrieve

7. Ground-Truth/Data Quality Issue
   - Root cause: Expected rule ID doesn't exist
   - Detection: Check fixture consistency
